# dreamSanta

A fully featured **dream marketplace** for the New Year. Create a wishlist, share it, get gifted — or organize a Secret Santa exchange with your friends or team.

My favourite project. Fully production-ready with SMS notifications and CryptoBot USDT payments.

## Features

- Personal wishlist builder — add dreams with images, prices, links
- Secret Santa organizer — create a group, invite participants, auto-match
- Public and private profiles
- SMS notifications for matches and updates
- CryptoBot USDT payments for gift budgets
- SEO-friendly pages
- Admin panel

## Setup

```bash
pip install -r requirements.txt
```

Set environment variables:
```env
SMS_API_KEY=your_sms_api_key
CRYPTO_BOT_TOKEN=your_cryptobot_token
SECRET_KEY=your_flask_secret
```

```bash
python run.py
```
